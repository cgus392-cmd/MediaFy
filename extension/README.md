# MediaFy Connector — Extensión para Chrome / Edge

Envía cualquier pestaña (YouTube, SoundCloud, TikTok, Spotify, Vimeo, Twitch, Instagram, Twitter/X, Facebook, Dailymotion, Bandcamp...) a **MediaFy by CG** para descargarla con un clic.

## Cómo instalarla (modo desarrollador, 30 segundos)

1. Asegúrate de tener **MediaFy** abierto al menos una vez, y de haber activado el **toggle del protocolo `mediafy://`** en
   *Configuración › Conexión externa*.

2. Abre tu navegador:
   - **Chrome**: ve a `chrome://extensions`
   - **Edge**: ve a `edge://extensions`

3. Activa **Modo desarrollador** (esquina superior derecha).

4. Click en **"Cargar descomprimida"** (Load unpacked) y selecciona esta carpeta:
   `extension/`

5. Listo. Aparece el icono de MediaFy en la barra de herramientas.

## Cómo se usa

- **Icono en la barra**: clic → descarga la pestaña actual.
- **Botón flotante**: aparece abajo a la derecha en sitios soportados.
- **Clic derecho** sobre un enlace → *"Descargar este enlace con MediaFy"*.
- **Popup**: clic en el icono → botón grande "Descargar esta página".

La primera vez el navegador puede preguntar *"¿Permitir abrir MediaFy?"*. Acepta y marca *"Recordar"*.
